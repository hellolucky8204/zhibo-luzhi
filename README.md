# 直播录制工作台 · Mac 基础测试版

本地后台录制与浏览器管理界面。关闭管理页面后仍可录制，电脑须开机、联网且不休眠。

## 功能

- 抖音直播间添加与开播监控、暂停、移除。
- 视频 MP4、音频 M4A，或同时保存两者。
- 360p、480p、720p，显示每小时存储估算。
- 一次性定时开始与结束，30 分钟分段，按主播与日期归档。
- 独立录制中页面、状态颜色、文件列表与下载。
- 断流重试、无数据重连、磁盘不足时暂停。
- 视频号代理取流为实验功能，需要电脑微信播放直播。

本版不包含蝉妈妈数据查询、文字转写、AI 分析、Windows 安装包。

## 安装与启动

安装 Python 3.12、Node.js 和 FFmpeg，将 Node.js 与 FFmpeg 加入 PATH。
在本目录执行：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# 可选：使用视频号代理取流时安装
.venv/bin/python -m pip install -r proxy-requirements.txt
bash start.command
```

页面地址 http://127.0.0.1:8769 。停止服务运行 `bash stop.command`。
录制存于 recordings/，本机配置存于 data/。不要提交这两个目录。

## 使用

抖音目前接受直播间链接，不接受主播主页链接。添加任务后开启监控即可。
视频默认 360p，视频含音频约 246 MB/小时；480p 约 403 MB，720p 约 718 MB。实际大小可能变化。

视频号：工作台启动取流代理，再运行配置视频号代理.command，选择当前网络并在本机确认管理员授权，然后重新打开微信直播。识别到候选源后创建录制任务。结束时先运行恢复视频号代理.command，再停止代理；stop.command 也会先恢复。

## 已知限制与验证

抖音与视频号均曾在开发机完成短时真实录制。音频、视频、双输出、暂停与定时已有本地测试；断流重解析和签名变化关联也已通过本地测试。

目前视频号重新打开直播后的候选源恢复仍未跑通，可能无法获取直播源；此功能以实验状态保留。没有视频号账号跨场自动开播监控。
尚未完成新 Mac 的完整安装验证、长时间录制、休眠恢复、原生安装包。请按测试版评估，不作为无人值守的正式交付版。

依赖：StreamGet（MIT）、FFmpeg（需自行安装）、mitmproxy（可选）。未打包第三方二进制，也未包含任何用户录制内容、密钥或代理证书。
