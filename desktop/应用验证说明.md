# Mac 应用验证说明

本目录为打包中的独立应用代码。运行环境打包后不需要用户安装 Python、Node.js 或 FFmpeg。

## 请朋友验证

1. 确认 Mac 为苹果芯片，记录 macOS 版本。
2. 下载对应的应用压缩包，将应用放入“应用程序”。
3. 打开应用，确认中文工作台能打开；系统安全拦截时先反馈，应用签名与公证仍待完成，不要求关闭系统安全保护。
4. 使用自己的微信，按界面配置视频号代理，授权后打开直播并创建录制任务。
5. 录制两分钟，停止录制并检查视频和声音；再验证依次打开三场能否同时录制。
6. 结束时点击恢复网络，再停止后台，确认微信可以正常联网。

请反馈：系统版本、应用是否启动、取流是否成功、录制是否正常、恢复网络是否正常、遇到的问题。不要发送密码、密钥、账号隐私或直播流完整地址。

云端打包和启动检查不能代替微信真实录制。未签名应用不作为正式公开安装版交付。
